Network Segmentation Case Study

Home Projects Network Segmentation

Network segmentation training lab

A configuration exercise using OPNsense to separate LAN, DMZ, and WAN traffic. The environment was provided for training; my work focused on firewall policy and host security configuration.

Security zones

LAN: internal workstation network. DMZ: Linux web server. WAN: upstream connectivity. OPNsense filters traffic between these zones.

Configured policy

Policy configured during the lab; this table is not a packet-level validation log.
SourceDestinationServicePolicy
LANDMZ web serverHTTPAllow
LANDMZOther trafficBlock
DMZWANDNS, HTTP, HTTPS, NTPAllow
DMZLANAll trafficBlock

Reasoning

The web server needed a narrow path for internal web access and selected outbound services. Blocking DMZ-to-LAN traffic reduced the paths a compromised web host could use to reach internal systems. SSH hardening and service review complemented network filtering.

Verification limits

The original rule export and traffic-test records are not attached. This page documents configured intent and does not establish production readiness or prove every traffic path was blocked. A repeatable validation would record allowed and denied connections, rule ordering, state behavior, and firewall logs.
